# Roadmap

## Phase 1: Bootstrap Foundation

- monorepo setup
- docs as source of truth
- shared contracts and config
- API scaffold
- mobile scaffold
- desktop runtime scaffold
- CI and deployment foundation

## Phase 2: Control Plane Integration

- Firebase / Identity Platform integration
- Firestore-backed session and device state
- command intake and approval workflow persistence
- operational alert routing

## Phase 3: Trusted Runtime Loop

- desktop heartbeat transport
- command polling and execution lifecycle
- session orchestration primitives
- transparent remote-session UX definition

## Phase 4: Analytics And Cost Intelligence

- BigQuery event pipeline
- budget monitoring and alert aggregation
- cost snapshots and operator dashboards
- Vertex-based explain and optimization workflows

## Phase 5: Hardening And Release Readiness

- IAM least-privilege review
- stronger audit trails
- smoke tests across runtimes
- mobile release workflow
- staged Cloud Run deployment validation
